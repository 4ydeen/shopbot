ShopVPN Integration API

احراز هویت با هدر Token انجام می‌شود. توکن را با دستور /token2 در ربات ادمین بسازید.

Scopeها

  • read: محصولات، پنل‌ها، دسته‌ها، تخفیف‌ها و تنظیمات مجاز.
  • users: خواندن کاربران.
  • orders: خواندن سفارش‌ها و پرداخت‌ها.
  • orders:write: برای API عمومی صادر نمی‌شود؛ بنابراین توکن read-only هرگز نمی‌تواند سفارش را تأیید کند.

محدودیت و لاگ

هر توکن حداکثر ۶۰ درخواست در دقیقه دارد (قابل تنظیم با متغیر API_RATE_LIMIT_PER_MINUTE)؛ بیشتر از آن پاسخ 429 با هدر Retry-After برمی‌گردد. همه‌ی درخواست‌ها در logs/api_access.log ثبت می‌شوند.

درخواست

POST /api
Token: shp_xxxxxxxxx
Content-Type: application/json

{"action":"products","limit":20,"offset":0}

پاسخ

{"status":true,"msg":"ok","obj":[...]}

Actionها

users، orders، payments، products، panels، categories، discounts، settings

مستندات تعاملی OpenAPI نیز در /api/docs در دسترس است.
